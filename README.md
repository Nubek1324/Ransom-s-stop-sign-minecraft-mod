# Ransom-s-stop-sign-minecraft-mod
# This mod is an addon for the [Ransom(A-90)](https://www.curseforge.com/minecraft/mc-mods/ransom-a-90) mod.

This mod adds only one item called the ransom's stop sign.
When a player gets hit byt the stop sign he gets the ransom to apear and the damage source player will discard the item.

The ransom's stop sign can only be stacked up to 1.
